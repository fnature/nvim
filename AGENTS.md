# Repository Instructions

- When making a git commit in this repository, update `CHANGELOG.md` in the
  same change unless the commit is purely mechanical and has no user-visible
  effect.
- Use dated `YYYY-MM-DD` headings in `CHANGELOG.md`, not `Unreleased`; this
  repository tracks changes by date, without a tag/release workflow.
- Keep Neovim configuration changes small and consistent with the existing
  `lazy.nvim` style in `init.lua`.
